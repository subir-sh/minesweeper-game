# ORBITAL BASE

`index.html`을 브라우저에서 열어 실행합니다.

## 구조
- `index.html`: 화면 마크업
- `css/style.css`: 전체 스타일
- `js/app.js`: 게임 상태, UI, 판정, 턴 진행
- `js/ai.js`: 솔로 플레이 AI
- `assets/`: 이미지 리소스

## 솔로 플레이
설정 화면에서 `솔로 플레이`를 선택하면 전문가 모드가 자동 적용됩니다.
- 초보 AI: 안전한 후보를 넓게 선택하고 복잡한 모순을 자주 놓칩니다.
- 고수 AI: 제약이 강한 수와 숨은 모순을 선호하고 선언 정확도가 높습니다.
